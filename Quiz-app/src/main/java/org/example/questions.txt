1. What is the correct way to declare a variable in Java?
A) var name;
B) int name;
C) name int;
D) declare int name;
Answer: B

2. Which of the following is a valid Java identifier?
A) 123variable
B) variable-name
C) variable_name
D) variable@name
Answer: C

3. What is the default value of an int variable in Java?

B) 1
C) null
D) undefined
Answer: A

4. Which keyword is used to create a class in Java?
